## 명부 독립성 검증

공개 지도 목록과 KOICA IATI를 읽고, 예산표와 대조한 뒤 사업 ID를 기록했다. 한국어·영어 표기와 위치를 보강한 다음 국가별 검토 명부와 지리 예외 파일 두 개를 모두 비운 상태로 다시 수집했다. 5개국에서 다시 선정된 ID가 실제 국·영문 PPT를 작성한 ID와 모두 같았다. 이 5개국은 원본을 이미 본 회귀검증 사례다.

- **예산 자료**는 ODA Korea 국제개발협력위원회 의결사항의 제56-2호(2026년 확정액)와 제58-1호(2027년 요구액)다. PDF 실물 77–129쪽과 66–96쪽의 외교부 소관 KOICA 국별 프로젝트·프로그램 행을 추출했다. JSON에 원문 SHA-256, 의결번호, 물리적 PDF 쪽수, 연간 금액과 계획기간이 있다. [정부 의결자료 목록](https://www.odakorea.go.kr/kor/bbs/PlanAndResulList?bbs_id=kor_001)
- **코스타리카 시설원예**는 제56-2호 PDF 119쪽의 2026년 확정액 1.98억 원과 제58-1호 PDF 90쪽의 2027년 계속사업 요구액 16억 원으로 발견했다. 협약 총액은 275만 달러다. IATI에서는 과테말라·엘살바도르·온두라스의 별도 활동 세 건에 코스타리카의 역할이 기재돼 있다. [코스타리카 외교부 협약 발표](https://www.rree.go.cr/index.php?cat=prensa&cont=593&id=8193&sec=servicios)
- **다른 국가 검증**에서는 에콰도르의 유엔난민기구 보호사업과 유니세프 아동영양 사업을 확인했다. 양쪽 모두 목적지정 기여(B03)이고 담당부서 기준 국별협력사업이다. 최종 규칙은 기존 IATI ID 2026010100084·2026010100161을 선택했다. 각 시행계획의 국문 행은 번역 중복 가능성이 있어 자동 추가하지 않고 편집기에 남긴다. 볼리비아에 같은 규칙을 적용했을 때 2027년 사업표 9행 중 4행은 기존 선정 활동과 일치했고 5행은 검토 대상으로 남았다. [KOICA IATI](https://www.odakorea.go.kr/opm/iati_act_KR-GOV-051.xml)

요구액은 연간 편성 요청이다. 제출된 금액만으로 협약 총액이나 2027년 실제 지출을 확정할 수 없다. 이 판본의 국별 계정 밖에 있거나 공식 문서가 아직 공개되지 않은 활동에는 추가 확인이 필요하다.

## 재생성

저장소 최상위 폴더에서 다음 명령을 실행한다. 입력 JSON은 공개 근거와 사업 ID를 포함한다.

```sh
skill/.venv/bin/python skill/scripts/make_map.py \
  --input examples/2027-five-country-round3/{thailand,jamaica,costa-rica,cuba,azerbaijan}.json \
  --page-format atlas-full --formats pptx --detail 10m --lang ko en --outdir output/round3-replay
```
